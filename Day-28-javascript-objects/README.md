# Day 28 - JavaScript Objects

## Overview

This project introduces JavaScript objects and demonstrates how related data can be grouped into a single object instead of being stored in multiple independent variables.

The Student Eligibility Dashboard was refactored by replacing individual student variables with a single `student` object while maintaining the existing application functionality.

This approach improves code organization, readability, scalability, and maintainability.

## Learning Outcome

Through this project, I learned how to organize related data using JavaScript objects. Instead of storing multiple variables for a single student, I grouped all student information into one object and accessed individual values using dot notation. This made the code cleaner, easier to understand, and more suitable for building scalable applications.
