# Day 23 - JavaScript Fundamentals

## Overview

This project marks the beginning of my JavaScript learning journey. The focus is on understanding the fundamentals of programming and how JavaScript adds behavior and interactivity to web pages.

The project demonstrates the use of variables, data types, operators, browser console output, and basic event handling.

---

## Topics Covered

- External JavaScript
- Variables (`const` and `let`)
- Primitive Data Types
- Arithmetic Operators
- `console.log()`
- Browser Developer Tools
- DOM Selection using `getElementById()`
- Event Handling with `addEventListener()`
- Browser Alerts

---

## Features

- Student information card
- Responsive layout using HTML and CSS
- Student data stored in JavaScript variables
- Console output for debugging
- Interactive button using JavaScript
- Alert displayed when the user clicks the button

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## Learning Outcome

Through this project I learned how JavaScript interacts with HTML, how variables store information, the difference between `const` and `let`, how to use the browser console for debugging, and how to respond to user interactions using event listeners.
