# Day 42 - JavaScript Switch Statement

## Overview

Day 42 focuses on the JavaScript `switch` statement.

A `switch` statement is useful when one value needs to be compared against several possible exact values.

In this project, a Student Status Checker was added to the existing Student Information project.

The user can select a student status and receive a different message depending on the selected value.

The objectives of Day 42 were:

- Understand the `switch` statement

# Concepts Learned

## 1. Switch Statement

The basic structure of a `switch` statement is:

```javascript
switch (value) {

    case "value1":
        // code
        break;

    case "value2":
        // code
        break;

    default:
        // fallback code
}
