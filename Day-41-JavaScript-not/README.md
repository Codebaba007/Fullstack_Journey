# Day 41 - JavaScript Logical NOT (`!`)

## Overview

Day 41 focuses on the JavaScript logical NOT operator (`!`).

The NOT operator reverses a boolean value:

- `true` becomes `false`
- `false` becomes `true`

This day builds on the logical operators learned previously:

- Day 38: Logical OR (`||`)
- Day 40: Logical AND (`&&`)
- Day 41: Logical NOT (`!`)

A small Student Access feature was added to the existing Student Information project to practice using `!` with a boolean variable and `if/else` logic.

---

## Project Objective

The objectives of Day 41 were:

- Understand the logical NOT operator (`!`)
- Understand boolean values
- Reverse boolean values
- Use `!` inside an `if` statement
- Track a student's selected/unselected state
- Change a variable's state using a button
- Connect JavaScript logic with DOM elements
- Display different messages depending on the student's state
- Practice `if/else` logic
