**# Day 44 - JavaScript Functions and Return Values**

**## Overview**

Day 44 focuses on JavaScript function return values.

In Day 43, I learned how to pass data into functions using parameters.

Day 44 builds on that concept by learning how functions can send a value back using the `return` statement.

Instead of only displaying information using `console.log()`, a function can return a value that can be stored in a variable, used in another expression, or passed into another function.

The exercises included returning student names, calculating averages, checking scholarship eligibility, and returning scholarship results from student objects.

**---**

**## Project Objective**

The objectives of Day 44 were:

\- Understand the `return` statement

\- Understand the difference between `console.log()` and `return`

\- Return values from functions

\- Store returned values in variables

\- Return calculated values

\- Use parameters together with `return`

\- Pass returned values into another function

\- Return values based on conditions

\- Return information from objects
