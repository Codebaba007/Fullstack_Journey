# Day 24 - JavaScript Conditionals

## Overview

This project focuses on introducing conditional statements in JavaScript and understanding how programs make decisions based on different conditions.

The project builds upon the previous JavaScript fundamentals by implementing comparison operators, Boolean logic, and conditional statements to evaluate student eligibility for scholarships, graduation, and attendance requirements.

---

## Topics Covered

- Comparison Operators
- Boolean Values
- `if` Statements
- `if...else` Statements
- `if...else if...else` Statements
- Conditional Logic
- Decision Making
- Console Output
- Variables and Data Types

---

## Features

- Student Eligibility Dashboard
- Student profile information
- Scholarship eligibility evaluation
- Attendance requirement evaluation
- Graduation eligibility evaluation
- Multi-condition academic evaluation
- Responsive user interface
- Professional dashboard layout

Through this project, I learned how JavaScript evaluates conditions, makes decisions using Boolean logic, and executes different blocks of code based on comparison results. I also gained a better understanding of how conditional statements form the foundation of interactive web applications and real-world programming logic.
