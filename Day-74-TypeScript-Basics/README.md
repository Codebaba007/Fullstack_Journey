## What is TypeScript?

TypeScript is JavaScript with an additional type system.

Instead of only writing:

```javascript
let age = 25;
```

TypeScript allows us to explicitly specify the expected type:

```typescript
let age: number = 25;
```

The `: number` part is called a **type annotation**.

TypeScript helps detect incompatible values before the program runs.

---

## Basic Types

### String

Used for text.

```typescript
let studentName: string = "Mehedi";
```

The variable is expected to contain a string.

```typescript
studentName = "Rahim";
```

Valid.

```typescript
studentName = 123;
```

Invalid because `123` is a number.

---

### Number

Used for numbers.

```typescript
let age: number = 25;
```

Valid:

```typescript
age = 26;
```

Invalid:

```typescript
age = "26";
```

Even though `"26"` looks like a number, it is actually a string.

---

### Boolean

Used for `true` or `false`.

```typescript
let isStudent: boolean = true;
```

Valid:

```typescript
isStudent = false;
```

Invalid:

```typescript
isStudent = "true";
```

`"true"` is a string, while `true` is a boolean.

---

## Type Annotations

A type annotation explicitly tells TypeScript what type a variable should contain.

Example:

```typescript
let studentName: string = "Mehedi";
let age: number = 25;
let isStudent: boolean = true;
```

The structure is:

```text
variable : type = value
```

For example:

```typescript
let age: number = 25;
```

means:

```text
age
 ↓
number
 ↓
25
```

---

## Type Inference

Type annotations are not always necessary.

TypeScript can often determine the type automatically from the initial value.

Example:

```typescript
let university = "UITS";
let semester = 7;
let graduated = false;
```

TypeScript automatically infers:

```text
university → string
semester   → number
graduated  → boolean
```

These are effectively understood as:

```typescript
let university: string = "UITS";
let semester: number = 7;
let graduated: boolean = false;
```

The difference is that in the second version, the types were explicitly written.

---

## Type Annotation vs Type Inference

### Explicit Type Annotation

```typescript
let age: number = 25;
```

The programmer tells TypeScript:

> `age` should be a number.

### Type Inference

```typescript
let age = 25;
```

TypeScript looks at `25` and determines:

```text
age → number
```

### Simple Mental Model

```text
Type Annotation
      ↓
I tell TypeScript the type

Type Inference
      ↓
TypeScript figures out the type
```

---

## Type Checking

TypeScript can detect incompatible assignments.

For example:

```typescript
let semester = 7;

semester = "eight";
```

TypeScript inferred:

```text
semester → number
```

Therefore assigning a string creates a type error.

But this is valid:

```typescript
let semester = 7;

semester = 8;
```

because both values are numbers.

---

## TypeScript Compilation

TypeScript source files use the `.ts` extension.

Example:

```text
index.ts
```

TypeScript can compile the file into JavaScript.

```text
index.ts
   ↓
TypeScript Compiler
   ↓
index.js
```

The TypeScript compiler is called:

```text
tsc
```

For a single file:

```bash
tsc index.ts
```

This produces:

```text
index.js
```

The generated JavaScript can then be executed with Node.js:

```bash
node index.js
```

---

## Why Does `index.js` Exist?

`index.ts` is the TypeScript source written by the developer.

`index.js` is the JavaScript output generated by the TypeScript compiler.

For example:

### TypeScript

```typescript
let age: number = 25;
```

### Generated JavaScript

```javascript
let age = 25;
```

The TypeScript-specific type annotation is removed during compilation because JavaScript does not use that syntax at runtime.

## Key Takeaways

1. TypeScript adds a type system to JavaScript.
2. `string` represents text.
3. `number` represents numbers.
4. `boolean` represents `true` or `false`.
5. Type annotations explicitly specify a type.
6. Type inference allows TypeScript to determine a type automatically.
7. Type annotations are not mandatory when TypeScript can safely infer the type.
8. `tsc` compiles TypeScript into JavaScript.
9. `index.ts` is the source file written by the developer.
10. `index.js` is the generated JavaScript file.
11. Node.js executes the generated JavaScript.
12. TypeScript can catch incompatible assignments before runtime.
