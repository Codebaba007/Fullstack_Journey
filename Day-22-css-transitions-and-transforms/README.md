# Day 22 – CSS Transitions & Transforms

## Overview

This project focuses on creating interactive user interfaces using CSS transitions and transforms. The objective is to improve user experience by adding smooth hover effects and subtle animations while maintaining clean and responsive layouts.

---

## Objectives

- Understand how CSS transitions work.
- Learn to animate specific CSS properties.
- Apply CSS transforms to move, scale, and rotate elements.
- Build interactive UI components with hover effects.
- Combine previous CSS concepts into a polished project.

---

## Concepts Practiced

### CSS Transitions

- `transition`
- `transition-property`
- `transition-duration`
- `transition-timing-function`
- `transition-delay`

### CSS Transforms

- `translate()`
- `scale()`
- `rotate()`
- Combining multiple transforms

### Visual Effects

- Hover effects
- Box shadows
- Border radius
- Image zoom
- Button animations

### Layout

- Flexbox
- CSS Grid
- Responsive Design
- Box Model

---

## Project Description

A modern product showcase was created consisting of multiple product cards.

Each card contains:

- Product image
- Category
- Product name
- Product description
- Product price
- Product rating
- Call-to-action button

Interactive effects include:

- Card lift animation
- Smooth shadow transition
- Image zoom on hover
- Animated button
- Responsive grid layout

---

## Learning Outcomes

After completing this project, I can:

- Create smooth UI interactions using CSS.
- Apply multiple transforms to a single element.
- Build reusable product card layouts.
- Improve user experience through subtle animations.
- Combine Flexbox, Grid, and animations into a complete component.
