# Day 29 - JavaScript Arrays

## Overview

This project introduces JavaScript arrays and demonstrates how multiple related values can be stored and managed within a single data structure.

The Student Management Dashboard was extended from working with a single student object to working with multiple student objects stored inside an array.

The project also introduces basic loops for iterating through the student collection and accessing individual object properties.

## Topics Covered

- JavaScript Arrays
- Array Indexes
- Array Length
- `push()`
- `pop()`
- Arrays of Objects
- Accessing Object Properties from Arrays
- `for` Loops
- Basic Data Processing

## Features

- Multiple student records stored in an array
- Access individual students using array indexes
- Access student properties using dot notation
- Add students using `push()`
- Remove students using `pop()`
- Count students using `length`
- Iterate through students using a `for` loop
- Calculate data from multiple student records

## Technologies Used

- HTML5
